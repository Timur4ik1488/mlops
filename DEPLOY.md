# 🚀 Деплой в один клик: https://timops.duckdns.org/

Проект настроен так, чтобы **не требовать никаких правок системных конфигов на сервере**.

Всё работает полностью автономно внутри Docker:
- Веб-сервер слушает порты `80` и `443`.
- **Автоматический SSL-сертификат** (Let's Encrypt) выдается и обновляется сам для `timops.duckdns.org`.
- Автоматический редирект с HTTP на HTTPS.
- SPA-роутинг и сжатие Gzip/Zstandard.

---

## ⚡️ Быстрый запуск на твоем сервере

### 1. Освободи порты 80 и 443 (если на сервере висит старый дефолтный Nginx):
Так как сейчас по адресу `timops.duckdns.org` показывается "Welcome to nginx", системный сервис Nginx занимает порты:
```bash
sudo systemctl stop nginx
sudo systemctl disable nginx
```

### 2. Запусти проект одной командой:
```bash
docker compose up -d --build
```
*(Или запусти готовый скрипт: `chmod +x deploy.sh && ./deploy.sh`)*
